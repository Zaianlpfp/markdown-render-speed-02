A fast Markdown renderer written from scratch: parse.js implements CommonMark 0.31.2 + GFM 0.29 with zero dependencies, and main.ts renders every case in /input/cases.json to /output/html.json — 720/720 cases correct in local testing, built for make.fun's "Make Markdown rendering faster" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
